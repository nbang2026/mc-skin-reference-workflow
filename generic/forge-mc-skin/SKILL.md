# 成品皮肤锻造 / MC Skin Forging

## 1. 职责范围

**输入**：经 `gather-mc-skin-refs` 产出的已校验素材集（或多张候选皮肤）。
**输出**：一张原创 64×64 Minecraft 皮肤（含 overlay 层），附三视图预览与校验报告。

### 能力边界

| 包含（本技能） | 不包含（交由 gather-mc-skin-refs） |
|---|---|
| 跨图部件拆解与拼装 | 角色识别与联网检索 |
| 方向性光影重着色 | 批量下载与完整性采集 |
| 面朝向光照渲染预览 | 素材原创性查重（拼装前由 A 完成） |
| 36 面完整性 + 可见性校验 | — |

本技能止于「成品皮肤」；素材的检索、下载与查重由 `gather-mc-skin-refs` 前置完成。

## 2. 触发条件

满足以下任一条件时调用：

- 已有参考素材，要求拼装成某角色的成品皮肤；
- 要求为角色从头制作一张 Minecraft 皮肤；
- 要求对既有皮肤施加方向性光影或重着色。

**不适用**：仅要检索/下载素材（转 `gather-mc-skin-refs`）。

## 3. 核心流程

1. **部件体检** —— 对候选素材逐部件扫描（头/躯干/双臂/双腿的顶/底/前/后/左/右），标记空洞与近白像素，仅取六面完整、配色有饱和度的来源。
2. **跨图拼装** —— 按 UV 坐标整块搬运部件（头取 A、躯干取 B、腿取 C），而非仅正面，避免侧面残影；不照搬单张，确保为拼装原创。
3. **光影重着色** —— 将头发/衣料映射到方向性色阶（光源定左上前方），保留分缕结构；近白结构（拉链/描边）加饱和度门槛保护，不被误改。
4. **面朝向渲染** —— 按 MC 规则（顶 1.0 / 正 0.8 / 侧 0.6 / 底 0.5）等轴测渲染前/右/顶三面，输出预览供目视复核。
5. **成品校验** —— 扫描 36 面无透明洞、配色有饱和度（避免游戏内糊掉），并做拼装后原创性差异率判定。

## 4. 关键原则

- 严禁整体照搬单张真实皮肤，必须跨图拼装。
- 禁用纯白/近白主色（饱和度≈0 在游戏高亮下不可见）；白色只做描边/小面积高光。
- 光影须方向性单调过渡，禁棋盘格抖动；单一主色系 + 冷暖对比，≥6 档色阶。
- 头/身/双臂/双腿的 36 面（含顶底面）必填，漏填即建模空洞。
