# 皮肤素材采集 / MC Skin Reference Gathering

## 1. 职责范围

**输入**：一张或多张角色参考图（或已知角色名）。
**输出**：一份经像素级验证的 Minecraft 皮肤素材集，存于独立目录，附筛选与来源报告。

### 能力边界

| 包含（本技能） | 不包含（交由 forge-mc-skin） |
|---|---|
| 参考图特征提取 | 皮肤部件拆解 |
| 多源检索与直链获取 | 跨图部件拼装 |
| 批量下载与完整性校验 | 颜色重映射 / 重着色 |
| 像素特征判定与分类 | 成品皮肤生成与 UV 校验 |
| 原创性查重与来源标记 | — |

本技能止于「可用素材集」；下游的部件拼装与成品生成由 `forge-mc-skin` 承担。

## 2. 触发条件

满足以下任一条件时调用：

- 提供角色参考图，要求检索并下载对应 Minecraft 皮肤；
- 提供角色名称，要求收集该角色的皮肤素材；
- 提及「找参考皮肤」「下载皮肤素材」「构建素材库」。

**不适用**：要求直接产出成品皮肤，或对既有素材做拼装改造（转 `forge-mc-skin`）。

## 3. 核心流程

1. **特征提取** —— 从参考图提取可检索标识（作品名、角色名中/英/罗马音）与校验特征（发色、瞳色及异色瞳左右分配、服饰款式、标志配件）。
2. **多源检索** —— 按可靠性降序：主源取皮肤直链，备用源按玩家名取皮，通用搜索兜底；主源失效自动回退。
3. **批量下载** —— 设浏览器 UA 绕过反爬，指数退避重试，幂等跳过已下载；单批 5–20 个（<5 强制扩查，>20 按可靠性截断）。
4. **像素校验** —— 尺寸白名单 `{64×64, 64×32}`；逐像素判定发色/瞳色/服饰是否吻合，剔除错标文件。
5. **原创性查重** —— 像素指纹（抓完全/近重复）+ 逐像素差异率（抓改色衍生）+ 可选 AI 视觉比对（抓语义同源）；命中者禁止标为原创。

## 4. 闭环自检

以整批为单位闭环：全批通过方进下一轮；程序环节失败整批重采，视觉复核失败仅剔单文件；连续三轮无进展主动中止并提示人工。

## 5. 关键原则

- 文件名不可信，一切以像素校验为准。
- 来源必须可追溯，报告逐文件标注出处。
- 零饱和度色（纯白）在游戏高亮下与背景融为不可见，须在校验阶段拦截。
- 素材隔离：下载物存独立目录，不污染、不覆盖既有文件。
